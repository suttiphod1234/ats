Advanced Analyzing Data With Power BI

ยกระดับการวิเคราะห์ข้อมูลด้วย Power BI ขั้นสูงสำหรับอุตสาหกรรมยานยนต์

กลุ่มเป้าหมาย

พนักงาน TBKK

วัตถุประสงค์หลักสูตร (Objectives)

  • Advanced Data Modeling
    เพื่อให้ผู้เรียนสามารถออกแบบโมเดลข้อมูล (Data Model) ที่ซับซ้อนในอุตสาหกรรมยานยนต์ได้อย่างมีประสิทธิภาพ
  • Advanced DAX & KPIs
    เพื่อให้ผู้เรียนใช้สูตร DAX ขั้นสูงในการคำนวณ KPI สำคัญ เช่น OEE, Scrap Rate และ Time Intelligence
  • Professional Dashboard
    เพื่อให้ผู้เรียนสร้าง Dashboard ระดับมืออาชีพที่ลดภาระงาน Manual และรองรับการ Refresh ข้อมูลอัตโนมัติ

เส้นทางการเรียนรู้ (Learning Flow)

1. Fundamental Strengthening (Foundation)

เริ่มด้วยการปรับจูนพื้นฐาน Model และ DAX เพื่อให้ทุกคนพร้อมรับเนื้อหาขั้นสูง

2. Advanced Logic Injection (Logic)

เติมตรรกะการคำนวณขั้นสูงและการวิเคราะห์เวลา เพื่อตอบโจทย์ธุรกิจโรงงาน

3. Structural Optimization (Structure)

วางโครงสร้างโมเดลให้รองรับ Big Data จากสายการผลิตของ TBKK ได้อย่างลื่นไหล

4. Storytelling & Interactivity (Presentation)

ฝึกการนำเสนอข้อมูลด้วย Visual ขั้นสูงเพื่อให้ผู้บริหารตัดสินใจได้ทันที

5. Connectivity & Scalability (System)

ขยายขีดความสามารถด้วยการเชื่อมต่อ API และตั้งค่าการอัปเดตข้อมูลอัตโนมัติ

6. Final Implementation (Application)

นำความรู้ทั้งหมดมาแก้โจทย์ Workshop จำลองการผลิตชิ้นส่วนยานยนต์ของ TBKK
